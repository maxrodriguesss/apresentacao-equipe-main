Entrar

Para salvar alterações, cole um token do GitHub com permissão de escrita no repositório . Ele fica guardado só neste navegador.

Como criar o token
  1. No GitHub, abra Settings › Developer settings › Fine-grained tokens › Generate new token.
  2. Dê um nome (ex.: "Admin equipe") e escolha a validade.
  3. Em Repository access, marque Only select repositories e escolha este repositório.
  4. Em Permissions › Repository permissions, deixe Contents como Read and write.
  5. Clique em Generate token, copie e cole aqui.

A ordem abaixo é a ordem do carrossel. Colaboradores ocultos ficam guardados, mas não aparecem na TV. Depois de salvar, o site atualiza em cerca de 1 minuto e a TV recarrega sozinha em até 2 minutos.
